# Fahad Al-Zuabi — Portfolio

A personal living portfolio showcasing my projects, professional experience, and an evolving hub of study resources for Information Technology courses.

🔗 **Live Website:** [fz3.netlify.app](https://fz3.netlify.app/)

---

### 📌 Overview
- **Projects:** Web applications, MySQL database design, and Java data structures.
- **IT Study Hub:** Summaries and resources for **IT241** (OS), **IT352** (HCI), **IT353** (System Analysis), and **IT354** (DBMS).
- **Experience:** Background in IT, Cybersecurity, and Mechanical Maintenance.

### 🛠️ Built With
- **HTML5 & Vanilla JavaScript**
- **Tailwind CSS** (Dark mode & Glassmorphism UI)
- **Thmanyah Font** & **Font Awesome Icons**
- Hosted on **Netlify**

### 🚀 Quick Start
No installation required. Clone the repo and open `index.html` in your browser:
```bash
git clone https://github.com/FAIIAD/MyPortfolio.git
```
